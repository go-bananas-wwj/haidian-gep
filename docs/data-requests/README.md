# 海淀区 2024 年度 GEP 数据请求包

这些模板对应唯一实施依据 `implementation/main.tex` 的第 2、3、6 章。它们用于向数据权利人索取可审核的 2024 年原始台账、监测或调查资料；**模板本身不构成数据、参数、适用性结论或发布授权**。

每次发出请求后，在受限数据目录中登记：请求编号、发送对象、日期、回执、附件原始文件 SHA-256、许可/保密要求、适用科目、字段映射及审核人。回复为空、未统计或不适用必须保留原始说明，不能转换为零值。

| 模板 | 责任渠道 | 覆盖科目 |
| --- | --- | --- |
| `01-agriculture-forestry-aquaculture.md` | 农业农村、园林绿化、经营主体 | P1--P4、P7、R12 |
| `02-water-energy-hydrology.md` | 水务、河湖/场站运营、电网 | P5、P6、R1、R5、R9 |
| `03-environment-regulating.md` | 生态环境、气象、水土保持、道路管理 | R2、R3、R8、R10、R11 |
| `04-culture-use-surveys.md` | 文旅、园林、公园、住房/酒店数据权利人 | C1--C3 |
| `05-boundary-and-spatial-base.md` | 行政区划、自然资源、园林绿化 | 全区边界、AlphaEarth 准入及空间归属 |

所有金额必须注明价格年度、币种、是否含税、单位和统计口径；所有空间数据必须注明 CRS、NoData、时间覆盖、有效面积和许可；所有表格须保留表头、脚注、空值含义及原件定位。
