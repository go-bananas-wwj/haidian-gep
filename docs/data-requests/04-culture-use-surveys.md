# 请求 04：2024 文化服务使用与景观归因资料

| 字段 | 颗粒度与单位 | 用途 |
| --- | --- | --- |
| 自然景区名录、去重入园人数、客源地、季节、目的、票务记录 | 景区/分层/年度 | C1 分层旅行成本；全区旅游收入不能替代 |
| 分层旅行问卷：时间、交通/住宿/门票成本、机会成本依据、归因 | 访客/样本权重 | C1 `N(tw+c)`；多目的旅行与 C2 重叠需说明 |
| 公园/绿道客流计数、抽样停留时间、工作日/节假日分层 | 场地/日期/时段 | C2 人时与扩推权重 |
| 2024 小时工资来源及年工资到小时的分母 | 人群/行业 | C1/C2 时间价值，不能用家庭收入替代 |
| 酒店实际入住间夜及年度服务价格 | 酒店/房型/年度 | C3 年度住宿服务流量 |
| 住房租赁/服务价格、受益面积、景观可达性与控制变量 | 样本级，受控访问可接受 | C3 特征价格或匹配；不接收资产成交总价替代年度服务 |
| 生态景观溢价模型、样本框、变量、模型版本与诊断 | 可复算材料 | C3 归因比例；没有可信对照时只能待补或区间估算 |

个人信息须先按数据权利人与隐私规范脱敏或受控访问；仍需保留样本框、变量定义、统计权重、时间范围和复算环境说明。
