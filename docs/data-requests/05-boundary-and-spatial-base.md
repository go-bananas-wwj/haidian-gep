# 请求 05：2024 海淀行政边界与空间底座确认

请提供或确认可用于 2024 年度核算的海淀区行政边界版本，不以 OSM 演示边界替代。文件应包含：发布机关、版本/生效日期、行政区代码 110108、原始格式、CRS、面积口径、许可、完整文件 SHA-256 和获取路径。

如提供街镇、林班、地块、水体、公园、道路绿带或经营单元，还须提供稳定对象 ID、拓扑/重叠规则、时间有效性、保密等级和与区界的关系。用于 AlphaEarth 处理时，将按所有 2024 相交资产筛选、局部文件哈希、64 维完整性、有效像元面积、空洞/重叠、CRS/仿射变换和分类留出验证验收；仅提供瓦片索引、bbox 候选或远程 VRT 不构成资产准入。
