# 请求 03：2024 调节服务环境、气象与工程资料

| 字段 | 颗粒度与单位 | 用途 |
| --- | --- | --- |
| 侵蚀力 R、土壤可蚀性 K、LS、月覆盖 C、面积与校核资料 | 单元级，注明 RUSLE 版本/单位 | R2 潜在与实际侵蚀差；降水量不能替代 R |
| 风速/风向、土壤粒径与含水率、粗糙度、覆盖及参考观测 | 时段/单元级 | R3 潜在/实际风蚀差与验证 |
| 功能区、站点浓度、有效率、SO2/NOx/颗粒物全源排放和治理成本 | 污染物/时段级 | R8 国标分支与污染物去除；浓度和排放不得混为一体 |
| 气温、湿度、蒸腾/水面蒸发、服务日、空调能效与电价 | 日/月级 | R10 仅核算实际发生的调节需求 |
| 同期近远侧噪声、道路/绿带几何、交通量、其他屏障、造价寿命 | 路段/时段级 | R11 对照降噪；dB 不可跨路段相加 |

每项请提供原件定位、空间参考、QC/缺测说明、参数出处、适用地域和许可。没有本地参数或独立校验时，应按“待补/待审估算”返回，不得提供无来源的总值。
