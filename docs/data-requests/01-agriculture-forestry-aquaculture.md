# 请求 01：2024 农业、林业、牧业与水产实际获取及投入台账

**核算期：** 2024-01-01 至 2025-01-01（366 天）；**区域：** 海淀区 110108。请提供可定位到原表/凭证的原件或受控访问路径。

| 字段 | 颗粒度与单位 | 用途 |
| --- | --- | --- |
| 主体、地块/塘口、产品/品种、批次 ID | 可关联代码 | P1--P4、P7 对象与唯一归属，防止父子产品或外购转售重复 |
| 播种/采收/捕捞日期、实际收获量 | 吨、立方米、株或盆；说明鲜干重/加工口径 | P1--P4、P7 年度实物量；不接受存栏/库存替代收获 |
| 本地生产、外购、转塘、转售标记 | 每个批次 | 剔除区域外来源，核对 P4 水产和 P3 牧产品适用性 |
| 2024 生产者价格与销售量 | 元/产品单位，价格基期 2024 | A.2 产出价值；不得以零售或含运输利润价格替代 |
| 中间消耗、劳动、折旧、生产税净额、正常资本回报 | 元/a，按同一产品边界 | P1/P2 A.2 残值；P3/P4/P7 如仅能提供 `production_cost`，须说明其完整组成与分摊规则 |
| 采伐许可、验收、林副产品采收或无采收证明 | 2024 主体/地点/日期 | P2 适用、已核实为零或实际获取结论 |
| 放牧资格/范围与肉奶毛草实际记录 | 2024 主体/产品 | P3 仅在国标适用条件已确认时使用 |
| 作物品种、产量、虫媒依赖依据与 P1/R12 选择 | 产品级 | R12 仅能排他归入 P1 或 R12，不得双计 |

请同时说明数据许可、隐私限制、负责人、更新日期和“空白/未统计/零/不适用”的原始定义。年鉴水产栏空白和 60 吨教学样例均不得用作本请求的正式数据。
